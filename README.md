# Givre

Appli web de défis quotidiens (90 jours et 30 jours), installable sur iPhone et Android.

Site statique publié avec GitHub Pages : `index.html`, `manifest.webmanifest`, `sw.js`, icônes.

## Serveur (Supabase)

Scripts à lancer dans l'ordre dans Supabase > SQL Editor : `supabase.sql`, `supabase-v2.sql`, `supabase-v3.sql` (groupes). Chacun peut être relancé sans risque.
